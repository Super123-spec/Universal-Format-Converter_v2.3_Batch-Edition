万能格式转换器 v2.1  使用说明
================================

【怎么用】
双击「万能格式转换器.exe」→ 等 6~8 秒出现窗口 → 把文件拖进窗口（或点「添加文件」）
→ 看「转换为」那一列是不是你想要的格式 → 点「开始转换」。

输出文件默认生成在原文件旁边，不会覆盖已有文件（重名会自动加 (1)）。
不需要安装任何东西，DWG 引擎和 ffmpeg 都已经打包在程序里。


【批量转换】
三个步骤，一次处理几十上百个文件：

  1. 拖一堆文件进来，或者点「添加文件夹」（会连子文件夹一起扫描）
  2. 「批量：全部设为」选一个目标格式 → 点「应用到全部」
     不支持的格式会自动跳过，日志里会写明跳过了几个
  3. 点「开始转换」

也可以只改一部分：在列表里选中若干行（支持 Ctrl+A 全选、Ctrl+点击多选），
再在「选中行转成」里设置。每个文件的目标格式都可以不一样。

小提示：
  · 同名文件转同一格式会自动加 (1)、(2)，日志里能看出哪个源文件对应哪个产物
  · 转换过程中可以点「取消」，当前文件结束就停
  · 大批量建议直接一次拖进来，不要反复添加——列表越长滚动越费劲



【支持哪些转换】(→ 表示可以转成)

  图纸    DWG / DXF          → PDF           ← 开箱即用，无需额外安装
  文档    DOCX / DOC         → PDF、TXT、互相转换（docx ↔ doc）
          XLSX / XLS         → PDF、CSV、互相转换（xlsx ↔ xls）
          PPTX / PPT         → PDF、互相转换（pptx ↔ ppt）
          CSV                → XLSX
          TXT                → DOCX
  PDF     PDF                → DOCX、XLSX、PPTX、PNG、JPG、TXT、DXF
  视频    MKV/MOV/AVI/FLV/
          WEBM/WMV/M4V/TS    → MP4、MP3、GIF
  音频    FLAC/WAV/M4A/AAC/
          OGG/WMA/MP3        → MP3、WAV、M4A、FLAC
  图片    HEIC/HEIF/PNG/JPG/WEBP/BMP/
          GIF/TIF/ICO/PPM/TGA  →  任意其他图片格式
          （可选：JPG、WEBP、PNG、PDF、BMP、GIF、TIFF、ICO）


【图片是"全互通"的】
任何图片格式都能转成任何其他图片格式，不用记谁转谁。共 13 种输入 × 8 种输出，
实测 65 条组合全部通过。几个常见用法：

  · JPG/PNG → ICO     自动生成 16/24/32/48/64/128/256 七种尺寸的方形图标，
                      非正方形的图会先补透明边，不会拉变形
  · 任意图 → WEBP     体积能小一半左右，网页用
  · HEIC → JPG        苹果手机照片在 Windows 上打不开时用
  · 截图 → PDF        每张图片一个 PDF 页

两条格式本身的限制（不是程序的问题）：
  · GIF 只有 256 色，照片转过去会有色带；动图只保留第一帧
  · JPG 不支持透明，透明区域会被填成白色



【旧格式升级：xls → xlsx 这类怎么用】
选中 .xls 文件，把「转换为」改成 XLSX 即可。反过来也一样。

这类转换走的是 Office 的"另存为"，所以合并单元格、边框、图片、公式、
行高列宽全都保留——实测一张 44 个合并单元格、带照片的申请表，转完
44 个一个不少，照片也在。和"转 PDF 再转回来"完全是两码事。

注意两点：
  · 转成 .xls 有硬上限（65536 行 × 256 列），超了会直接拒绝，不会悄悄截断
  · .xls 不支持新版本特性（迷你图、部分条件格式），转换时会提示



【几条必须知道的限制】

1. 文档转 PDF 用的是你电脑上的 Microsoft Office
   所以版式和你在 Office 里看到的一致。前提是本机装了 Office；
   如果只装了 WPS，这条路会失败（界面底部会提示）。

2. PDF 转 Excel 是"表格还原"
   程序会找出 PDF 里带框线的表格，填进工作表；没有表格的页会把文字按行
   放进单独的工作表。扫描件（图片型 PDF）里没有可识别的文字，转不了。

3. PDF 转 PPT 是"每页一张图"
   版式 100% 保留，但幻灯片里的文字不可编辑。要改字请用 PDF→DOCX。

4. PDF 转 CAD 是"线条级"的，不是真 CAD 对象
   PDF 里没有图层、图块、标注这些 CAD 语义，所以转出来的 DXF：
     · 线和曲线能保留，可以量取尺寸、可以继续描图
     · 文字可能变成曲线轮廓
   要真正能编辑的 CAD 图纸，源头必须是 DXF/DWG。

5. 视频转 MP3 需要视频里本来就有声音
   无声录屏会直接提示"没有音轨"，这是正常的。


【小技巧】
· 一次可以拖多个文件，也能拖整个文件夹（点「添加文件夹」）
· 选中多行 → 在上面的下拉框里选目标格式 → 点「应用」，可以批量改
· 一个 PDF 可以同时加两次，分别设成 XLSX 和 DOCX，一次出两种结果
· CAD 出图默认 A3 横向，如果原图有自己的图框，选「自动」更贴合
· 视频转码和复杂图纸吃时间，进度条走完才算完，中途别关窗口


【出问题怎么办】
转换失败的原因会写在下方「日志」区，把那几行发出来就能定位。


【能不能拷到别的电脑用】
可以，整个程序就这一个 exe，不需要安装、不需要 Python。但要分清哪些能用：

  对方电脑是 Windows 10/11（64 位）且装了 Microsoft Office
      → 全部功能可用

  对方电脑是 Windows 但没装 Office（只有 WPS 也算没有）
      → 文档转 PDF 用不了，界面底部会提示「Office 缺失」
        CAD、PDF、图片、音视频、表格互转全部照常

  对方电脑是 Mac / Linux
      → 跑不了，只支持 Windows

  学校机房 / 别人的受限账户
      → 一般能跑，但可能被杀毒软件拦（见下）

几条实际会遇到的坑：

  · 杀毒软件可能误报
    这种"单文件打包"的程序容易被 360、火绒报毒（不是真有毒，是打包方式触发误判）。
    先加白名单再运行，或者让 IT 帮忙放行。

  · 首次运行 Windows 可能弹「已保护你的电脑」
    点「更多信息」→「仍要运行」即可。这是没做数字签名的正常提示。

  · 文件 187MB，邮件附件发不了
    多数邮箱限制 25MB。用网盘、U 盘或微信传。放 U 盘里可以直接双击运行，
    但拷到本地硬盘再跑会快不少。

  · 每次启动要等 7~9 秒
    单文件版每次启动都要把内部组件解压到临时目录，属于正常现象，不是卡死。

  · 建议连同原文件一起保存
    PDF 是"当时的版式快照"，不能替代原始 xlsx/docx。
